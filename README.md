## 发布
GitHub Pages 使用 main 分支根目录。修改 index.html、style.css、script.js 或 assets/，提交后自动更新。
发布新软件版本时，先上传 Release 附件，再同步下载链接、版本号、大小和日期。旧版 Release 保留。

## 数据与资料
本仓库只有网页及使用合成资料的软件截图，不含个人简历、聊天数据库、API Key 或安装包。
页面未额外接入统计服务；GitHub Pages 会记录访客 IP 地址用于安全目的，请参阅 GitHub 的隐私政策。
